# رفيق · راديو — الإصدار 0.2.2

راديو إنترنت وقرآن للتلفزيون، يتحكم فيه بالريموت. مكتوب بـ HTML وJavaScript عادي بلا أي بناء، ويعمل على الكمبيوتر وعلى تلفزيون سامسونج (Tizen 5 فأحدث).

## ثلاثة أوضاع في نفس الملفات

| الجهاز | الشكل |
| --- | --- |
| التلفزيون | الشكل الأصلي 1920×1080، يتحكم فيه بالريموت. يتعرف تلقائياً على سامسونج وLG |
| الكمبيوتر (أعرض من 900 بكسل) | عدد الأعمدة على قد الشاشة، سكرول بالماوس، والكيبورد شغال زي الريموت |
| الموبايل والتابلت (900 بكسل أو أقل) | عمودين على الموبايل وثلاثة على التابلت، الأقسام شريط أفقي فوق، ومشغّل صغير تحت |

لمعاينة شكل التلفزيون على الكمبيوتر: افتح `http://localhost:8000/?tv=1`.

## الجديد في 0.2

- **دول العالم:** كل الدول التي لها محطات في الدليل، الدول العربية أولاً ثم الباقي حسب عدد المحطات. أسماء الدول بالعربي وأعلامها.
- **الأنواع:** أنواع المحطات العربية (مستخرجة من أشهر 500 محطة عربية) ثم الأنواع العالمية (بوب، أخبار، جاز…).
- **كل المحطات العربية:** باللغة العربية من كل الدول، الأكثر استماعاً أولاً.
- **سمعتها مؤخراً:** آخر 30 محطة شغّلتها.
- **تحميل المزيد:** آخر كل قائمة، 60 محطة في كل مرة حتى نهاية الدليل.
- **البحث بالاسم أو النوع:** لو الاسم جاب نتائج قليلة يضيف المحطات الموسومة بنفس الكلمة.
- **عدد محطات الدليل** يظهر بجانب الاسم.
- التخزين المؤقت محدود بـ 40 قائمة، ويحذف الأقدم تلقائياً لما مساحة التلفزيون تمتلئ.
- زر **رجوع** داخل دولة أو نوع يرجعك لنفس المكان في القائمة.

## التجربة على الكمبيوتر

1. فك الملف في فولدر.
2. افتح Terminal داخل الفولدر واكتب:
   `python -m http.server 8000`
3. افتح Chrome على `http://localhost:8000`.
4. اضغط F11 لملء الشاشة.

(فتح `index.html` بالضغط المزدوج يعمل غالباً، لكن الطريقة السابقة أضمن.)

## التثبيت على تلفزيون سامسونج

1. نزّل **Tizen Studio** مع إضافة **TV Extensions** من موقع Samsung Developers.
2. على التلفزيون: Apps ← اكتب **12345** بالريموت ← فعّل **Developer mode** واكتب IP الكمبيوتر ← أعد تشغيل التلفزيون.
3. في Tizen Studio: **Device Manager** ← أضف التلفزيون بالـ IP.
4. **Certificate Manager** ← أنشئ شهادة Samsung (تحتاج حساب Samsung).
5. **File ← Import** هذا الفولدر كمشروع Tizen Web، ثم **Run As ← Tizen Web Application**.

## الملفات

| الملف | الدور |
| --- | --- |
| `js/stations-seed.js` | قائمة البداية المنتقاة (عدّل المحطات هنا) |
| `js/sources.js` | الأقسام، والدول والأنواع، والصفحات، ودليل Radio Browser، وإذاعات mp3quran، والتخزين المؤقت |
| `js/countries-ar.js` | أسماء كل الدول بالعربي (من بيانات Unicode) |
| `js/player.js` | التشغيل، وتجربة الروابط البديلة، وإعادة الاتصال، ومؤقت النوم |
| `js/nav.js` | التنقل بالأسهم حسب مكان العناصر على الشاشة |
| `js/app.js` | الشاشات وأزرار الريموت |
| `config.xml` | إعدادات تطبيق Tizen وصلاحياته |

## ما تم اختباره وما لم يُختبر

- **اختُبر في Chromium** ببيانات وروابط وهمية: التنقل، والتشغيل، والرابط البديل، والمحطة المتوقفة، والمفضلة بالأرقام، ومؤقت النوم، وإطفاء الشاشة، والبحث، والعمل بلا إنترنت من آخر نسخة محفوظة.
- **في 0.2 اختُبر بنفس الطريقة:** الدول والأنواع، والدخول والرجوع، وتحميل المزيد حتى نهاية القائمة، والمحطات الأخيرة، والبحث.
- **لم يُختبر**: البث الحقيقي للمحطات، واستجابة Radio Browser وmp3quran الفعلية، وتلفزيون سامسونج حقيقي.
- محطات HLS (`.m3u8`) تحمّل مكتبة hls.js من الإنترنت عند الحاجة.
